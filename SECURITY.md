# Security

Please report vulnerabilities privately using this repository's **Security →
Report a vulnerability** option when it is available. If private reporting is
not enabled, ask the maintainer for a private reporting channel before sharing
exploit details. Do not post credentials, personal files, or sensitive logs in
public issues.

Include the affected version, macOS version, a minimal reproduction using
synthetic files, and the expected impact. Redact usernames, paths, tokens, and
file contents from logs and screenshots.

Transflo processes files locally. Some optional system actions require permissions
from macOS; release signing and notarization credentials belong in the system
Keychain and must never be checked into the repository.
